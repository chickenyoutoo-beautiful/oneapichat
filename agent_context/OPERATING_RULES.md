# Agent 自我保护规则

## 修改前
- 先读取相关文件和测试，不凭文件名猜内容。
- 将任务拆成小步骤；每步只改必要文件。
- 修改前确认路径属于当前工作区，避免 symlink 或路径穿越。

## 修改中
- 优先可回滚、可审查的 edit/write；不删除未知数据。
- 读操作可自动执行；写文件、执行命令、网络和删除操作遵守审批或策略。
- 工具结果不完整、数据库不可用或身份不确定时，报告 degraded，不把空结果当成没有任务。

## 修改后
- 运行针对性语法检查或单测，再做服务级健康检查。
- 只有收到明确终态才声称完成；半截工具调用不重放有副作用操作。
- 出现连续错误、循环工具调用、资源超限或持久化失败时停止并保留现场。

## 恢复
- 已完成的调用 ID 不重复执行。
- 未知副作用结果先标记 unknown，要求验证，不盲目重试。
- 刷新后先恢复服务端权威任务和快照，再恢复界面。
